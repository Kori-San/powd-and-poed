# Task files

- Copy `tasks/_TEMPLATE.md`. Keep its sections in the same order.
- The title is the task id and a verb phrase: `v1-07 Make shooting feel good`.
- The file is `tasks/vN/NN-verb-phrase.md`.
- The goal is one sentence.
- Steps are a numbered checklist of at most seven. The first step is small enough to start right away.
- Every "Done when" line can be checked by running something or looking at one thing.
- "Learn" has at most three concept lines, at most one "Try it", and exactly one "Explain it back".
- The size is S, M, or L. Split anything bigger than L.
- A task file is 50 lines or fewer.
- Never renumber a task once work on its version has started. A new task takes the next free number.
- Add the task to its version board in the same commit.
